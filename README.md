# 🤖 AI机器人·成长营 — 学习网站

基于 **AI机器人模块课程体系** 打造的机器人教育学习网站，面向 5-8 岁、9-12 岁、13 岁+ 三个年龄阶段，共 12 门课程、48 课时。

## 📁 项目结构

```
├── index.html              # 首页 - 课程浏览
├── curriculum.html          # 课程体系总表
├── course-detail.html       # 课程详情页
├── demo.html                # 招生展示课
├── deploy.sh                # 部署脚本
├── README.md                # 本文件
├── css/
│   ├── style.css            # 主样式表
│   └── detail.css           # 详情页样式
├── js/
│   ├── courses-data.js      # 课程数据（12门课 + 3个展示课）
│   ├── script.js            # 首页交互逻辑
│   └── detail.js            # 详情页逻辑
└── app/                     # 各课程独立页面（可选）
```

## 🎯 课程体系

| 阶段 | 年龄 | 课程 | 课时 |
|------|------|------|------|
| 🟢 启蒙期 | 5-8岁 | R01-R04 | 16课时 |
| 🔵 成长期 | 9-12岁 | R05-R08 | 16课时 |
| 🟣 硬核期 | 13岁+ | R09-R12 | 16课时 |

### 启蒙期（5-8岁）
- **R01** 机器人初探与感知世界 — 零件认知、搭建、运动控制、传感器
- **R02** 声音魔法师 — 声音传感器、声控编程、蜂鸣器音乐、互动剧场
- **R03** 机械小达人 — 杠杆、齿轮、滑轮、机械手臂
- **R04** AI小侦探 — AI视觉、人脸识别、物品分类、目标跟随

### 成长期（9-12岁）
- **R05** 机器人编程与AI感知 — 系统架构、Python编程、传感器、AI视觉
- **R06** 仿生机器人创意工坊 — 仿生设计、六足机器人、仿生鱼、创意发明
- **R07** 智能家居机器人 — 系统设计、环境监测、语音交互、安防系统
- **R08** 竞技机器人 — 循迹算法、避障算法、竞赛策略、模拟竞赛

### 硬核期（13岁+）
- **R09** 机器人底层开发与AI核心 — ROS、SLAM建图、深度学习、自主导航
- **R10** 人形机器人开发 — 运动学、步态规划、手势识别、表演编排
- **R11** 无人机与空中机器人 — 飞行原理、飞控编程、AI航拍、搜救任务
- **R12** AI机器人竞赛特训 — 竞赛设计、路径规划、多机协同、模拟竞赛

## 🚀 本地运行

直接用浏览器打开 `index.html` 即可，无需构建工具。

## ☁️ 部署到阿里云

```bash
# 方式一：使用部署脚本
chmod +x deploy.sh
./deploy.sh

# 方式二：手动 scp
scp -r * root@120.76.98.45:/www/wwwroot/airobot.zengqi.site/
```

### Nginx 配置参考

```nginx
server {
    listen 80;
    server_name airobot.zengqi.site;
    root /www/wwwroot/airobot.zengqi.site;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
```
